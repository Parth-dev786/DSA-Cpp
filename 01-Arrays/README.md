## Learning Approach

For every important concept or algorithm, I aim to understand:

- What is it?
- Why does it exist?
- How does it work?
- When should I use it?
- When should I NOT use it?
- What problem does it solve?
- What is the intuition?
- How do I implement it in C++?
- What is the time and space complexity?
- Can I explain it without looking at my notes?
